In Shortcuts, use an NFC automation to open this link. Each new visit advances the preview.

  1. Create a shortcut with Random Number (1 to 999999999), then URL.
  2. Paste the link above. Replace NUMBER with the Random Number variable.
  3. Add Open URLs. Run once to test.
  4. On iOS 26 or earlier: Automation → + → NFC, scan one sticker and select this shortcut. Choose Run Immediately if offered. On iOS 27: open the shortcut → Edit → Automation → NFC.

The extra number gives Safari a fresh URL for every tap. Keep the phone unlocked for the first test. Reset returns to Golden hour.

This page simulates lighting. It does not read NFC or control physical lights. Your iPhone reads the sticker and runs the shortcut.
